# 研究地图阅读模式（本地）

2026-10-16：按读者关注点选择信息，全部研究资料仍保留。

- 总览脉络：显示全部52节点的简洁标题，默认隐藏详情、来源和边界；点击节点展开详情。
- 关注算法：可连续添加20个已整理方法主题中的多个主题，标签可移除。
- 关注问题：可多选8个具体问题主题或6个应用方向。
- 自定义：多选六条主线与年代，可只看关键节点，切换节点摘要、详情、来源、边界、邻接节点和可见关系。
- 布局：时间地图或紧凑列表；隐藏没有结果的年代与主线，减少空白。
- 记忆：浏览器本地保存阅读设置，存储不可用时仍可正常阅读；恢复默认可清空筛选状态。

主题多选取并集，再与年代、主线、关键词取交集。只有已有明确关系的相邻节点会作为“邻接”加入，使用虚线边框和文字区分；同样受年代、主线与关键词约束。算法主题只覆盖已收录研究，不冒充全部算法谱系；问题关联不构成行业适用性保证。

配置在 data/research_reading_views.json，纯筛选逻辑在 js/research_reading.js。修复了新补节点中三个旧应用别名，使其能对应已有应用卡。源码资料保持原样，渲染时统一别名。
