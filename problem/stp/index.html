斯坦纳树 Steiner Tree Problem（STP）

抽象问题类型 · Ⅸ 选址与网络设计类（开-关向量编码）

In brief

The Steiner Tree Problem connects a set of terminals at minimum total length using optional extra Steiner points; it is NP-hard. The site solves the discrete version over a given point set: one bit per candidate Steiner point and the minimum spanning tree of terminals plus chosen points as the objective, which cannot match the Euclidean Steiner tree whose extra points are free; instances are small enough to enumerate.

抽象定义

模型：给定图 G=(V,E,w) 与终端集 T⊆V，求总权最小的子树，连通全部终端（可以经过非终端的「斯坦纳点」）：

min w(T′)  s.t.  T′ 是 G 的子树，T ⊆ V(T′)

T=V 时就是最小生成树（多项式）；|T|=2 时是最短路径（多项式）；介于两者之间是 NP-困难——这是「中间状态更难」的经典例子。欧氏斯坦纳树（平面上任意位置可加斯坦纳点）与图斯坦纳树是同一思想的两个变体；关键性质：最优斯坦纳树的每个斯坦纳点度数 ≥ 3，且度数为 3 的点三条边两两成 120°（欧氏情形）。

应用：芯片布线（VLSI 全局布线）、通信网设计、系统发育树。

与同族问题的结构差异

与 MST 的差别在于可以引入额外的点来缩短总长：三个点构成的正三角形，最小生成树长 2，斯坦纳树（取中心点）长 √3≈1.73。斯坦纳比（最小生成树 / 斯坦纳树）在欧氏平面上至多 2/√3≈1.1547（Du–Hwang 1992 证明了 Gilbert–Pollak 猜想），所以用 MST 近似斯坦纳树已有不错的下限保证。

  • 参数化：固定终端数 k 时是 FPT（Dreyfus–Wagner 1971 的 O(3ᵏn) 动态规划）。
  • 最优解可由 MST 表达：图上最优斯坦纳树恰好是「终端 ∪ 某个斯坦纳点子集」的最小生成树——这是把斯坦纳树编码成「哪些斯坦纳点入选」的位向量的理论依据。

求解路径

  • 近似：Kou–Markowsky–Berman (1981) 的最短路径 MST 启发式，近似比 2；Zelikovsky (1993) 11/6；Byrka、Grandoni、Rothvoß 与 Sanità (2013) 的 LP 随机取整达到 ln4+ε≈1.39，是图斯坦纳树的当前最好理论比。欧氏平面有 PTAS (Arora 1998)。
  • 精确：Dreyfus–Wagner 动态规划；分支切割加归约技术（SteinLib 实例上数千点可求最优）；欧氏情形的 GeoSteiner 先枚举「全斯坦纳树」再拼接。
  • 启发与元启发：Takahashi–Matsuyama 最短路径启发式；对「选哪些斯坦纳点」做位向量搜索的 GA / SA / 禁忌搜索，是这类问题的标准元启发式编码。

计算复杂度与可近似性

NP-困难（Karp 1972，图情形；Garey–Graham–Johnson 1977，欧氏情形也是）。图斯坦纳树 APX-困难 (Bern & Plassmann 1989)，不能被近似到 96/95 以内，除非 P=NP (Chlebík & Chlebíková 2008)；欧氏与直线度量下有 PTAS (Arora 1998)。有界树宽的图上多项式可解；固定终端数 FPT。

基准实例与已知结果

标准库是 SteinLib（Koch、Martin 与 Voß 2001 起维护，收录来自 VLSI、随机图、完全图、几何图的几百个实例，最优值多数已知），以及 DIMACS 第 11 届实现挑战赛（2014）的斯坦纳树赛道与 PACE 2018 的参数化竞赛。评价指标是与已知最优的 gap 或求解时间。

本站的建模方式

词条域位向量变体（保真度：标准模型）：平面上 n=8–14 个点，随机取 max(3, n/3) 个为终端（图上标成蓝方块），其余点是候选斯坦纳点；解 = 每个候选点一位（要不要当中转点）；目标 = 终端 ∪ 入选中转点在完全欧氏图上的最小生成树总长。「最优斯坦纳树就是某个点子集的最小生成树」保证了这个编码不丢最优解。

与文献标准的差别：这是在给定的点集里选斯坦纳点（离散图版本），不是欧氏斯坦纳树——后者的斯坦纳点可以放在平面任意位置，所以这里的最优值可能比欧氏最优长；规模小（≤ 2¹¹ 种子集）可用枚举求最优，因此各算法大多能找到最优；没有用 SteinLib 的格式。
