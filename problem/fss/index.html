流水车间调度 Flow Shop Scheduling（FSS）

抽象问题类型 · Ⅰ 排序与巡回类（排列编码）

In brief

The permutation Flow Shop minimises the makespan when all jobs visit the machines in the same order; it is strongly NP-hard for three or more machines (Johnson's rule solves two machines). The default instance is Taillard's ta001 (20 jobs × 5 machines, known optimum 1278) and the page draws a Gantt chart with the lower bound; smaller sizes use the same generator. It is a single easy instance family (NEH+IG reaches the optimum in seconds).

抽象定义

模型：置换流水车间（permutation flow shop, PFSP）——n 个作业依次经过 m 台机器（机 1 → 机 2 → … → 机 m），所有机器上的作业顺序相同，作业 j 在机器 k 上要加工 p[k][j] 单位时间；一台机器同时只能做一个作业，一个作业同时只能在一台机器上。最小化最后一个作业在最后一台机器上的完工时间（makespan，Cmax）。完工时间由递推给出：

C(j,k) = max( C(j−1,k), C(j,k−1) ) + p[k][π(j)]，Cmax = C(n,m)

应用：装配线、半导体封装、化工批处理、流水线上的订单。Johnson (1954) 证明 m=2 时有 O(n log n) 的最优规则（Johnson 规则）；m≥3 起就是强 NP-困难 (Garey、Johnson 与 Sethi 1976)。

与同族问题的结构差异

在车间调度三兄弟里，流水车间约束最强：所有作业路线相同，只剩「顺序」一个自由度，所以解 = 一个排列，搜索空间 n!。对照：

  • 作业车间：每个作业有自己的机器路线，自由度多得多；
  • 开放车间：作业的机器顺序也不规定，由调度者决定；
  • 置换 vs 非置换：一般流水车间允许各机器上顺序不同（非置换），最优可以更短，但置换版本是实践与基准的标准。m≤3 时置换调度对 Cmax 总是最优。

求解路径

  • 构造启发式：NEH（Nawaz–Enscore–Ham 1983）——按总加工时间降序逐个插入最佳位置——至今仍是最强的构造法，Taillard (1990) 的加速使每次插入评价 O(m) 摊销。
  • 迭代贪婪（IG）：Ruiz & Stützle (2007)——破坏（随机移除 d 个作业）+ 重建（逐个最佳插入）+ 局部搜索，简单而强，是 Taillard 基准上长期的领先算法之一。
  • 禁忌搜索：Nowicki & Smutnicki (1996)——基于关键路径块的邻域，是求解 Taillard 难例的里程碑。
  • 元启发式（本站算法轴的常驻战场）：遗传算法、粒子群、蚁群、差分进化的置换版都有大量文献；Ruiz & Maroto (2005) 对 25 种启发式与元启发式做过全面评价。

计算复杂度与可近似性

m=2 多项式（Johnson 规则），m≥3 强 NP-困难 (Garey、Johnson 与 Sethi 1976)。近似：固定 m 时有 PTAS (Hall 1998)；一般情形，Williamson 等 (1997) 证明不存在比 5/4 更好的多项式近似，除非 P=NP（对流水 / 开放 / 作业车间同时成立）。实用上：Taillard 的 20 作业 5 机实例（ta001–ta010）用 NEH + IG 瞬间可解到最优；50 作业 20 机以上的实例才是真正的难例，大量最优值至今未证明。

基准实例与已知结果

标准基准是 Taillard (1993) 的 120 个实例（ta001–ta120，作业数 20/50/100/200/500 × 机器数 5/10/20，加工时间 U[1,99]，用公开的伪随机数发生器和种子生成，所以可以精确复现），其中 20×5、20×10、20×20 等小规模部分已解到最优；Vallada、Ruiz 与 Framinan (2015) 的「新难例」（VRF，240 个大实例）用来补 Taillard 太容易的部分。评价指标：相对最好已知值的百分比偏差 (ARPD)。

本站的建模方式

词条域里的排列编码变体（保真度：标准模型）：默认实例就是 Taillard 的 ta001（20 作业 × 5 机器，时间种子 873654221，加工时间 U[1,99]，文献最优 Cmax=1278，页面用蓝虚线标出）；其他规模（5–19 作业）用同一发生器按页面种子生成。解 = 作业的排列，目标 = 完工时间 Cmax（上面的递推），页面画甘特图，绿虚线是下界（每台机器总时间加上前后最短的前置 / 后继）。

与文献标准的差别：只有一个 5 机的小规模实例族；ta001 属于「容易」的一类，NEH+IG 几秒钟就能到最优 1278（本站的测试里也核对了这一点：存在一个排列恰好达到 1278，且随机排列不会更好）；要体验真正的难例，请导入 Taillard 的 50×20 以上实例（导入格式见页面）。
