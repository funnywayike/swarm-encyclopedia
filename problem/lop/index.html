线性排序问题 Linear Ordering Problem（LOP）

抽象问题类型 · Ⅰ 排序与巡回类（排列编码）

In brief

The Linear Ordering Problem ranks n items to maximise the total weight of pairwise preferences that agree with the order; it is NP-hard and appears in input–output table triangulation. The site uses the standard model with n = 5–12 on random asymmetric matrices, which lack the upper-triangular dominance of real tables; for n ≤ 12 an exact subset DP is possible, so most algorithms find the optimum quickly.

抽象定义

模型：给定 n×n 权重矩阵 w，找 {1..n} 的排列 π，最大化「排在前面的项对排在后面的项」的权重之和：

max_π Σ_{i<j} w[π(i)][π(j)]

等价地：对一个有权竞赛图，删掉权重和最小的一组弧使其无环（最小反馈弧集）。它是 Kemeny (1959) 排名聚合的数学内核——n 个评委各给一个排名，找一个与所有评委总体分歧最小的共识排名（Dwork 等 2001 把它用到网页排名）。另一个经典应用是投入产出表的三角化（Leontief）：把经济部门排成「上游→下游」的顺序，使表里「向后」的流量最小；赛事积分与循环赛排名同理。

与同族问题的结构差异

排列问题里的特殊成员：目标是成对关系的线性函数——交换相邻两项只改变一对的贡献，所以邻域评价是 O(1) 的，插入邻域的增量也能 O(n) 算出，局部搜索特别高效。

  • 与 TSP / QAP 的对照：同样是排列，TSP 的目标只依赖相邻对（环），QAP 是二次的；LOP 依赖全部前后对，但每一对独立、可加——结构介于二者之间。
  • 最大化 vs 最小化的近似落差：最大版本（最大无环子图）平凡的随机排序就是 1/2 近似，且唯一游戏猜想下不可能更好；最小版本（反馈弧集）则连常数近似都被唯一游戏猜想排除。
  • 稠密情形是例外：权重在竞赛图（每对都有）上的 LOP 有 PTAS (Arora–Frieze–Kaplan 2002；Kenyon-Mathieu & Schudy 2007)。

求解路径

  • 精确：Grötschel、Jünger 与 Reinelt (1984) 的割平面算法是经典；n≈40–60 内有分支切割能解，更大的实例靠元启发式。小 n（≤ 20 左右）用子集动态规划（O(2ⁿ·n)）直接精确求解。
  • 启发与元启发（本站算法轴的主场）：插入邻域局部搜索、迭代局部搜索、禁忌搜索、memetic 算法；Schiavinotto & Stützle (2004) 分析了 LOP 的搜索空间并比较了多种算法，Martí & Reinelt (2011) 是专著。
  • 近似算法：KwikSort（Ailon、Charikar 与 Newman 2008）用随机轴点快速排序，得到 11/7 (期望) 的排名聚合近似。

计算复杂度与可近似性

NP-困难（Karp 1972：反馈弧集；Garey–Johnson GT8），最大版本同样 NP-困难。最大无环子图在唯一游戏猜想下不可能优于 1/2+ε 的近似 (Guruswami、Manokaran 与 Raghavendra 2008)，即随机排序已是最优；无条件的不可近似性只有 65/66 (Newman 2000)。对稠密 / 竞赛图实例有 PTAS。精确求解可做到 O(2ⁿ·n)（Held–Karp 型动态规划），所以 n ≲ 25 的实例是「易解」的。

基准实例与已知结果

标准基准库是 LOLIB（Reinelt 起维护）：49 个 44 部门的真实投入产出表 (IO)，加上 Mitchell–Borchers 的随机实例 (RandA/B)、SGB（Stanford GraphBase）实例，以及 Schiavinotto & Stützle (2004) 的 XLOLIB（大规模）。多数小实例的最优值已知，比较指标是与最好已知值的百分比差。

本站的建模方式

词条域里的排列编码变体（保真度：标准模型）：n=5–12，权重 w[i][j]（i≠j）取 [1,20] 的随机整数，是非对称矩阵；目标 = Σ_{i<j} w[π(j)][π(i)]，取负后最小化。

与文献标准的差别：这是随机实例，没有投入产出表的结构（真实 IO 表有明显的上三角占优，随机矩阵没有）；n ≤ 12 时 2¹² 状态的子集动态规划即可精确求解，所以各算法多半能很快找到最优；规模与 LOLIB 不可比。
