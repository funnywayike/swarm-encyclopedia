DTLZ 三目标基准 DTLZ Scalable Test Problems (3 objectives)（DTLZ）

抽象问题类型 · Ⅷ 多目标抽象类（前沿编码）

In brief

DTLZ is a family of scalable multi-objective test problems whose number of objectives can be chosen freely. The site includes DTLZ1–7 with exactly three objectives, runs NSGA-II, MOEA/D, a weighted-sum GA and random search, and reports IGD and the hypervolume ratio against reference points sampled from the analytic front. It does not show DTLZ's main selling point — scaling to 5, 8 or 10 objectives.

抽象定义

模型：DTLZ 是目标数可任意扩展的基准族。本站取 3 个目标（原文的 DTLZ1–7 全部收录），决策变量 x∈[0,1]ⁿ 分成两段：前 2 个变量 (x₁, x₂) 决定「在前沿曲面上的位置」，其余 k 个变量通过 g 决定「离曲面有多远」，g = 0 时就在真前沿上。

  • DTLZ1（n=7，k=5）：g = 100·[k + Σ((xᵢ−0.5)² − cos(20π(xᵢ−0.5)))]；f₁ = ½x₁x₂(1+g)，f₂ = ½x₁(1−x₂)(1+g)，f₃ = ½(1−x₁)(1+g)。真前沿是平面 f₁+f₂+f₃ = 0.5。g 里的余弦项制造了 11⁵−1 个局部前沿，多峰，收敛很难。
  • DTLZ2（n=12，k=10）：g = Σ(xᵢ−0.5)²；f₁ = (1+g)cos(x₁π/2)cos(x₂π/2)，f₂ = (1+g)cos(x₁π/2)sin(x₂π/2)，f₃ = (1+g)sin(x₁π/2)。真前沿是单位球面的第一卦限 f₁²+f₂²+f₃² = 1。单峰，主要考三维前沿的覆盖是否均匀。
  • DTLZ3（n=12）：g 同 DTLZ1（余弦项），形状同 DTLZ2。真前沿仍是单位球面，但有 3¹⁰−1 个局部前沿，最难收敛的一个。
  • DTLZ4（n=12）：同 DTLZ2，但把 x₁、x₂ 换成 x₁¹⁰⁰、x₂¹⁰⁰。真前沿不变，可是随机解几乎都挤在 f₃ ≈ 0 的面上，考多样性维护：算法容易只覆盖前沿的一小块。
  • DTLZ5（n=12）：第二个角度 θ₂ = π/(4(1+g))·(1 + 2g·x₂)，g = 0 时恒为 π/4。真前沿退化成一条曲线（f₁ = f₂，f₁²+f₂²+f₃² = 1），而不是一块曲面——这是「前沿维数低于目标数」的典型。
  • DTLZ6（n=12）：同 DTLZ5，但 g = Σ xᵢ^0.1，g 在 0 附近极其陡峭，收敛很难。
  • DTLZ7（n=22，k=20）：f₁ = x₁，f₂ = x₂，f₃ = (1+g)·h，g = 1 + 9/k·Σxᵢ，h = 3 − Σ fᵢ/(1+g)·(1+sin 3πfᵢ)。g = 1 时是一块带起伏的曲面，其中非支配的部分是互不相连的 4 块，f₃ 的量级（到 6）也比 f₁、f₂ 大得多。

与同族问题的结构差异

与 ZDT 的区别：目标数从 2 变成 3，前沿从一条曲线变成一块曲面，「铺开」变得更难——同样 60 个个体，在二维前沿上很密，在三维曲面上就稀了；这也是 IGD 的数值下限不会趋于 0 的原因（点数有限）。

指标和 ZDT 页相同：IGD（真前沿上的参考点到算法前沿的平均距离）与超体积占比（参考点 (1.1,1.1,1.1)；DTLZ1 的前沿很小，取 (0.6,0.6,0.6)）。

目标数继续增加（≥4）后，基于支配的排序会失去区分度，见超多目标优化。

求解路径

算法与 ZDT 页相同。看点：

  • DTLZ2：NSGA-II 与 MOEA/D 都能收敛到球面，区别在覆盖——MOEA/D 的参考方向来自预先放好的权重格（Das–Dennis 单纯形格点），NSGA-II 靠拥挤度。
  • DTLZ1：同样的预算下，NSGA-II 往往被局部前沿困住，分解型的 MOEA/D 则能到达真前沿附近——这是该基准被设计出来的目的（Deb et al. 2005）。
  • DTLZ3：本页的算法在默认预算内都到不了真前沿（有 3¹⁰−1 个局部前沿）；把迭代次数拉到 500 以上再试，看谁能爬出来。
  • DTLZ6：NSGA-II 在默认预算内收敛不了，分解型的 MOEA/D 能到真前沿附近。
  • DTLZ4：看覆盖——前沿上被算法忽略的部分在图上一眼可见。
  • DTLZ5：前沿是曲线；DTLZ7：前沿四块不相连，种群得分到四块上去。
  • 加权和 GA 在三维前沿上只会集中到少数几个点。

默认迭代 200；DTLZ1 想收敛得更好可以拉到 300 以上。

计算复杂度与可近似性

目标数 m 增大后，DTLZ 暴露出多目标特有的复杂度：（1）前沿是 (m−1) 维流形，覆盖它所需的解数随 m 指数增长——用 Das–Dennis 参考点网格（每轴 H 等分）需要 C(H+m−1, m−1) 个点，m=3、H=12 时是 91 个，m=10、H=3 时就有 220 个；（2）精确超体积计算在 m 上是 #P-困难的 (Bringmann & Friedrich 2010)，所以 m>5 之后常改用蒙特卡洛估计；（3）随机两个解互相支配的概率是 2^{1−m}，m=3 时仍是 1/4，m=10 时只剩 1/512（见超多目标页）。

基准实例与已知结果

DTLZ1–7 是多目标 / 超多目标进化算法的通用考题，标准设置：目标数 m 从 3 到 15 变化；位置变量数 m−1，距离变量数 k 取 DTLZ1 为 5、DTLZ2–6 为 10、DTLZ7 为 20（所以决策变量 n=m+k−1）；用 IGD 或 HV 度量，IGD 的参考点集用 Das–Dennis 网格投影到真前沿。较新的 MaOP 基准如 MaF 套件 (Cheng 等 2017)与 WFG、以及 PlatEMO 平台（Tian 等 2017）里统一实现的版本，都以 DTLZ 为蓝本又加上了退化、不连通、偏置等性质。已知的缺陷：DTLZ1–4 的最优解的距离变量都在 0.5（变量范围的正中），中心偏置的算子会占便宜。

本站的建模方式

mocont 域：目标数固定为 3，DTLZ1–7 全部收录，n 分别为 7、12、12、12、12、12、22（即 m+k−1）。真前沿的参考点集由解析式取样，指标为 IGD 与超体积占比（参考点 (1.1,1.1,1.1)，DTLZ1 取 (0.6,0.6,0.6)）。算法与 ZDT 页相同：NSGA-II、MOEA/D、加权和 GA、随机搜索。

与文献标准的差别：（1）只有 3 个目标，没有展示 DTLZ 本来的卖点——目标数的可扩展性（5、8、10、15）；（2）最优解的距离变量在 0.5（范围正中），中心偏置会让一些算子得到偏好；（3）NSGA-II 用的是原版拥挤度，而不是 NSGA-III 的参考点选择，所以它在 3 目标的 DTLZ1/3 上表现不佳是预期内的；（4）没有 WFG 那样的变量依赖，所以不能代表复杂耦合的真实问题。
