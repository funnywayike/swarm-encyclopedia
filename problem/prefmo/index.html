偏好多目标范式 Preference-Based EMO（PREFMO）

抽象问题类型 · Ⅷ 多目标抽象类（前沿编码）

In brief

Preference-based evolutionary multi-objective optimisation steers the search towards a region of interest given by a reference point. The site implements a simplified R-NSGA-II on the mocont domain (ZDT1, ZDT2, DTLZ2): NSGA-II selection by distance to a fixed reference point with ε-clearing; the reference point is drawn as a diamond. It supports only one fixed reference point, and IGD is naturally large because the method concentrates on a small part of the front.

抽象定义

模型：多目标优化的一类范式——决策者的偏好在搜索中起作用，而不是先求出整条 Pareto 前沿再事后挑选。按偏好何时进入分为三类 (Hwang & Masud 1979)：先验（搜索前给出权重、目标值、参考点）、交互（搜索中反复征询）、后验（先求前沿再选，即 NSGA-II 这类）。

参考点法：min_x max_i wᵢ·(fᵢ(x) − zᵢ)  （z = 决策者的愿望点，w = 归一化权重；Wierzbicki 的成就标量化函数）

偏好表达的常见形式：权重、目标优先序（字典序）、目标值上下限（目标规划）、参考点 / 愿望点（最直观：「我想要 f₁≈0.3、f₂≈0.4」）、成对比较。它在工程里的意义：目标一多（≥4）整条前沿既不可视也不必要，只需要决策者关心的那一小块，称为兴趣区域（ROI）。

与同族问题的结构差异

与 NSGA-II 型（后验）的差异：偏好法的算力集中在 ROI，不求整条前沿；代价是需要决策者事先表达偏好，而人往往要看到可能性才知道自己要什么——这是后验法与交互法存在的理由。

  • 加权和的陷阱：用权重把多目标合成一个目标，只能找到前沿凸包上的支持解（Geoffrion 1968），在凹前沿（如 ZDT2）上无论怎么调权重，都找不到中间段；参考点 / Tchebycheff 型标量化则没有这个限制。
  • 愿望点位置影响很大：愿望点在前沿「内侧」（不可达）时，结果是离它最近的前沿点；在「外侧」（可达，已被超越）时，算法应收敛到前沿上该点附近。实现里必须对这两种情形都稳健。
  • 评价指标不同：整条前沿的 IGD / HV 会惩罚偏好法（它本来就没打算铺满前沿），要用 ROI 内的指标或到参考点的距离。

求解路径

  • R-NSGA-II（Deb 等 2006）：NSGA-II 的骨架 + 同一前沿内按到参考点的距离选择 + ε-清除保持多样性。
  • 基于目标规划与权重的早期工作：Fonseca & Fleming (1993) 把目标向量（goal）的偏好并入 Pareto 排序；Wierzbicki (1980) 的参考目标法是数学规划里的对应物。
  • 交互式进化：Branke 等编的文集 (2008) 汇集了交互式与进化式方法；Thiele 等 (2009) 的偏好进化算法在搜索中周期性询问决策者对参考点的更新。
  • 综述：Marler & Arora (2004) 对工程里的多目标方法做了系统分类；Bechikh 等 (2015) 专门综述了进化算法中的偏好并入。

计算复杂度与可近似性

偏好法把多目标化为一个单目标子问题（每个参考点一个），所以单次求解的代价与单目标版本相同——这正是它的卖点；难度也完全继承单目标版本，对 NP-困难的组合问题仍然是 NP-困难。决策者的参与则引入另一种复杂度：交互轮数与认知负担，没有标准的理论刻画。数学上有两个值得知道的事实：加权和只能到达支持解 (Geoffrion 1968)；Wierzbicki 的成就标量化函数则可以在适当参数下到达任何 Pareto 最优解（含非支持解）。

基准实例与已知结果

偏好法没有统一的基准集：通常复用 ZDT / DTLZ，为每个函数指定若干参考点（前沿内侧 / 外侧各一个），用 ROI 内的 HV 或到参考点的最短距离来评价，也有专门设计的偏好指标 (Mohammadi 等 2013)。因此结果的可比性取决于参考点怎么选、ROI 怎么定义——报告时必须给出参考点的具体取值。

本站的建模方式

mocont 域上的 R-NSGA-II 简化版，可在 ZDT1 / ZDT2 / DTLZ2 上跑：NSGA-II 骨架，前沿内按到参考点（目标已按各函数尺度归一化）的欧氏距离选择，ε=0.02 清除，其余同 NSGA-II（SBX、多项式变异）。参考点由程序给定：从理想点出发朝真前沿「正中点」方向走 85%（略好于前沿、不可达）；图上用菱形标出，并报告当前前沿到它的最短距离。与文献标准的差别：参考点是固定的，不能交互修改；只有一个参考点（R-NSGA-II 支持多个）；ε-清除参数不可调；没有归一化的自适应更新。默认指标 IGD 会因偏好法只铺满一小段而偏大，这是预期，不是缺陷。
