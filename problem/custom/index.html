自带问题
选解的形状 · 写目标函数 · 全部算法可用

本站没有你要的问题？把它描述出来：解长什么样（编码），好坏怎么算（目标函数）。其余——几十种算法、收敛曲线、结果导出与复现——都是现成的。

所有算法都只通过两样东西和问题打交道：解的形状（编码）和目标值。所以你只要给出这两样，同一批算法就能原样跑你的问题：

  • 位向量：n 个是/否的决策——选哪些渠道、开哪些仓库、用哪些特征。
  • 排列：把 0..n-1 排个顺序——任务先后、路线顺序、装配次序。
  • 实数向量：n 个在 lo~hi 之间的数——参数调优、曲线拟合、函数最小化。

目标函数怎么写？（语法与限制）

写法像 Python 的表达式：可以有几行 名字 = 表达式 的中间量，最后一行直接是目标值（或写成 objective = …）。

  • 可用：数字、+ - * / // % **、比较、and or not、a if 条件 else b、下标 x[i]、列表 / 生成式（sum(w[i] * x[i] for i in range(n))）。
  • 可用函数：sum min max abs len range sorted round float int any all sqrt exp log sin cos floor ceil zip enumerate，常数 pi e。
  • 不可用：import、点号属性、字符串、lambda、字典 / 集合、for / while 语句、def。循环最多嵌套两层。
  • 约束请用罚函数：违反约束就加一个大数 × 违反量，例如 gain - 100 * max(0, spend - budget)。

常见问题

我的目标函数会被当作代码执行吗？
不会。目标函数只是一段「表达式」：本站先把它解析成语法树，逐个节点检查，只放行数字、四则和乘方、比较、推导式、以及 sum / min / max / abs / sqrt 等少数白名单函数；import、属性访问（点号）、字符串、lambda、循环语句一律拒绝。解析通过后才编译成只会做算术的小程序，每次评价还有迭代次数和整数大小的上限，防止写出会卡死标签页的式子。
为什么没有 for 循环、while 循环？
表达式风格的 sum(… for i in range(n)) 已经能写出绝大多数目标函数（求和、最大最小、加惩罚项），而且循环层数有限、次数有上限，不会死循环。如果你的目标函数确实需要完整的 Python（递归、复杂状态），请用命令行：python swarm.py solve 数据.json --domain custom --objective-py 你的函数.py，那是在你自己的电脑上运行你自己的文件。
约束怎么写？
用罚函数：违反约束就在目标里加一个大数乘以违反量，如 gain - 100 * max(0, spend - budget)。惩罚太轻，算法会专挑违反约束的便宜解；太重，可行与不可行之间没有梯度。示例里的「预算内选渠道」就是这个写法，可以改着试。
为什么三种编码对应的算法数不一样？
每种编码复用本站已有的一批内核：位向量用 QUBO 那批，排列用装箱 / 图着色那批，实数用连续函数那批。内核不是为你的问题写的，但它们只通过「编码」和「目标值」与问题打交道，所以能原样跑。算法不一定适合你的问题——最好多挑几个比一比。
结果可靠吗？
「最优值」是算法在你的目标函数上找到的最好值，不保证是全局最优。随机算法换个种子结果会变；要下结论请多换几个种子。导出的结果文件带着完整的问题定义，别人可以用 python swarm.py replay 复现。
