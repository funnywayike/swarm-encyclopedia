最大独立集 Maximum Independent Set Problem（MIS）

抽象问题类型 · Ⅱ 子集与选择类（0-1 编码）

In brief

Maximum Independent Set asks for the largest set of vertices with no edge between any two of them; it is NP-hard and hard to approximate in general graphs, while bipartite graphs, trees and chordal graphs are easy. Here it runs as the `mis` variant of the colouring-family domain: a 0/1 vector with a repair step that deletes a conflicting endpoint, so every candidate is a valid independent set. Instances are random graphs; a degree-ascending greedy serves as the deterministic reference.

编码 0-1 向量（点选/不选）复杂度 NP-hard（Karp 21 问题）等价 MIS(G)=MCP(G̅)，MIS+VCP=n近似 不可 n^(1−ε) 近似（Håstad）

抽象定义

模型：图 G=(V,E)，选最大点集 S 使任意两点不相邻：

max Σᵢ xᵢ  s.t.  xᵢ + xⱼ ≤ 1 (∀{i,j}∈E),  x∈{0,1}ⁿ

约束是「成对冲突」型的 0-1 规划——每条边砍一刀超立方。Karp 1972 的 21 个 NP-complete 问题成员（以 CLIQUE 名义：CLIQUE(G)=MIS(G̅)，G̅ 为补图）。带点权的版本（MWIS）把目标换成 Σ wᵢxᵢ。

典型应用：无冲突调度（点 = 任务，边 = 资源冲突）、无线网络里互不干扰的链路同时激活（冲突图上的独立集）、编码理论（最大码字集）、计算机视觉里的特征匹配一致性筛选。

与同族问题的结构差异

与背包家族同用 0-1 编码，结构差异在约束与等价关系上：

  • 约束形态：背包是一条求和约束 Σwᵢxᵢ≤C；MIS 是 m 条成对约束（每条边一条）——编码同族、地形完全不同。
  • 精确互补关系：S 独立 ⇔ V∖S 是顶点覆盖，故 MIS + VCP = n 恒成立（两问题等价）；MIS(G)=MCP(补图) 是归约等价三角的第三边——一个问题会解，三个全会解。
  • 可近似性天壤之别：背包有 FPTAS；MIS 在一般图上不可在 n^(1−ε) 内近似（Håstad 1999）——这是「问题选择决定方法天花板」的最锋利教案，也解释为何元启发式在此是主力而非点缀。

求解路径

  • 构造 + 局部搜索是主力：最小度贪心保证 n/(d̄+1)（Turán 界）；Andrade–Resende–Werneck (2012) 的 ARW 迭代局部搜索（(1,2)-交换：去掉一个点、加入两个点）是大规模稀疏图上的标准基线。
  • GRASP 经典：Feo–Resende–Smith (1994) 的 GRASP-for-MIS 是 GRASP 框架的奠基实验之一（与 SCP、TSP 并列）。
  • 精确方法：在顶点覆盖一侧用「分支 + 归约规则」，Akiba–Iwata (2016) 的 branch-and-reduce 能精确解掉数百万顶点的稀疏图；稠密图则通常转成最大团交给 MCS 类算法。
  • 与 QUBO 轴对接：MIS 的二次惩罚形式 xᵀAx（边罚 1）是 QUBO / 伊辛机的标准测试映射，量子退火文献里的 MIS 实例比比皆是。

计算复杂度与可近似性

NP-困难（判定版 NP-完全）。一般图上近似几乎无望：Håstad (1999) 证明除非 NP=ZPP，否则对任意 ε>0 不存在 n^(1−ε) 近似，Zuckerman (2007) 把前提去随机化为 P≠NP。多项式可解的重要图类：二分图（König 定理：MIS = n − 最大匹配）、树与森林、弦图、完美图（Grötschel–Lovász–Schrijver 1981，借助 Lovász 数）。参数化视角下以解的大小为参数是 W[1]-难。

本站的建模方式

本站把 MIS 放在着色家族域（gcvar）的 mis 变体里：0/1 位串编码，目标 = −|S| + 10000 × 冲突边数；修复算子遇到冲突就删掉度数较大的那个端点，所以搜索看到的永远是合法独立集。算法集是位向量的通用算法（GA、PSO 位版、SA、TS 等）；确定性对照是「度升序贪心」。实例是随机图，节点数可调（10–120），能下载 / 上传 JSON 格式的图（边列表）。与文献标准的差别：只支持无权版本；不读 DIMACS 的 .clq / .col 格式以外的大规模稀疏图——上传上限由浏览器内运行的性能决定。
