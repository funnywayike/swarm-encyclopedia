生成式设计 Generative Design（GD）

抽象问题类型 · 开放登记（谱外新类：优化场景与应用专题）

In brief

Generative design uses algorithms to propose layouts or shapes under rules. The site models the smallest possible layout problem: 5–12 circular blocks to place in a 100×100 site without overlap and with some pairs wanting to be adjacent (a 2k-dimensional real vector). There are no daylight, circulation or structural criteria and it is a simplified teaching model, not a real design problem.

抽象定义

模型：生成式设计（generative design）——不是人逐个画方案，而是给出设计规则与目标，由算法自动生成并优化大量候选方案。在建筑、机械、电路板布局里，最小的一类是布局生成：

把 k 个功能块（有尺寸）摆进场地：块间不重叠、满足邻接偏好、总体性能（采光、动线、材料……）最优

它和 QAP（设施布局）、圆 / 矩形装填、floorplanning 是近亲；区别在于生成式设计强调方案的多样性（给设计师多个可选的好方案）与多目标（性能、成本、美观无法统一）。Krish (2011) 提出了一种实用的生成式设计方法，Shea、Aish 与 Gourtovaia (2005) 讨论了性能驱动的生成式设计工具。

与同族问题的结构差异

与传统优化的差别主要在流程：参数化模型 → 生成大量方案 → 按性能评价 → 筛选 / 展示给设计师。优化只是其中一环；Oxman (2006) 把这看作设计方法论的数字化转向。

  • 目标不唯一：多目标进化算法给出一个 Pareto 方案集，设计师在集合里选；
  • 评价昂贵：真实设计的性能评价（日照模拟、结构有限元）很贵，代理模型是常规配置（见昂贵黑箱）。

求解路径

  • 进化计算：遗传算法 / 进化策略搜索参数；Bentley (1999) 的论文集是早期代表。
  • 形文法 / 规则系统：用规则语法生成方案空间，再用优化筛选。
  • 拓扑优化：在结构设计里用连续体拓扑优化（SIMP 方法）生成材料布局，是工程里最成熟的生成式设计。

计算复杂度与可近似性

布局问题大多 NP-困难：圆 / 矩形装填、floorplanning、QAP 都是强 NP-困难；多目标性质使「最优」成为一个集合。真实设计问题没有统一的复杂度刻画，规模受限于性能评价的开销。设计空间通常是混合变量（连续尺寸 + 离散拓扑）的高维空间，加上评价昂贵，所以实践里的目标是「得到足够多样且足够好的方案」，而不是证明最优。

基准实例与已知结果

生成式设计没有统一的基准：因为设计问题千差万别。相关的标准基准来自它的子问题：圆装填（Packomania 的最优 / 最好已知装填记录）、floorplanning 的 MCNC / GSRC 基准电路、QAPLIB（布局型）。评价常用「方案多样性 + 性能达标率」。

本站的建模方式

词条域里的实数向量变体（保真度：教学简化模型）：k=5–12 个圆形功能块（半径 6–14），摆进 100×100 的场地，要求互不重叠并留 2 个单位的间隙；约 35% 的块对「希望相邻」。解 = 每个块的 (x, y)（2k 维实数向量，[−5,5] 线性映射到场地内）；目标 = 重叠量的平方 ×5 + 希望相邻的块之间多出来的距离。页面画圆，红圈 = 重叠，虚线 = 希望相邻。

与文献标准的差别：只有「不重叠」与「希望相邻」两条规则，没有采光、动线、结构等真实设计指标，也不是多目标；它是生成式设计里最小的布局生成模型，不是真实的设计问题。
