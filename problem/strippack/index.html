条带装箱 Strip Packing Problem（SPP）

抽象问题类型 · Ⅳ 划分与装填类（划分/装填编码）

In brief

Strip Packing places rectangles in a strip of fixed width and unbounded height and minimises the height used; it is strongly NP-hard, but its approximability is milder than that of 2D bin packing (AFPTAS exists). The site uses a permutation encoding with a shelf decoder on a strip of width 100, so only shelf layouts are reachable and rotation is not modelled; instances are random, not the benchmark sets of the literature.

抽象定义

模型：宽度为 W、高度无限的条带，排入 n 个矩形物品，互不重叠、轴平行，最小化占用高度：

min H  s.t.  所有 wᵢ×hᵢ 矩形放入 [0,W]×[0,H]，两两不重叠

与二维装箱的对偶关系：SPP 把「箱数」放松成「开放高度」——固定宽度、优化高度；反之 2D-BPP 固定箱、优化个数。最朴素的高度下界是 LB = max(⌈Σwᵢhᵢ / W⌉, max hᵢ)（面积下界与最高物品），是一切算法的起跑线。工业里对应「卷材 / 板材一刀切到头」的排版：钢板切割线、印刷卷筒、纺织面料排料。

与同族问题的结构差异

与二维装箱（2D-BPP 页）的成对关系是本页的教学核心：

  • 开放维度不同：2D-BPP 箱数离散开放、高度封死；SPP 高度连续开放、宽度封死。
  • 近似理论的主场：条带模型是二维装填里最「干净」的形式，所以几乎所有二维装填的近似结果（NFDH / FFDH / Steinberg / AFPTAS）都先在这里证明，再推到装箱。
  • 与一维的联系：所有物品宽度相同、条带宽度是其整数倍时，退化为多机调度；全部物品都等宽于条带时，高度就是高度之和。

求解路径

  • 分层启发：先按高度降序，NFDH（下一个适合）、FFDH（首次适合）是 O(n log n) 的基线，已知界：NFDH ≤ 2·OPT + hmax，FFDH ≤ 1.7·OPT + hmax（Coffman–Garey–Johnson–Tarjan 1980）；bottom-left 规则的界是 3·OPT（Baker–Coffman–Rivest 1980）。
  • 近似算法：Steinberg (1997) 的绝对近似比 2；Kenyon & Rémila (2000) 的渐近 FPTAS；Harren 等 (2014) 把绝对近似比推到 5/3+ε。
  • 元启发线：GA（排列编码 + 放置规则解码）与 SA 在 Hopper & Turton 的综述里被系统对照——条带装箱是二维排样元启发式的公共试验台。
  • 精确：Martello–Monaci–Vigo (2003) 的分枝定界；高度二分 + 约束规划 / 整数规划的混合在中小规模常达最优。

计算复杂度与可近似性

强 NP-困难。绝对近似比不可能好于 3/2（由 PARTITION 归约：物品都等高，条带宽度取总宽的一半，OPT=2h 当且仅当存在完美划分）；已知最好的绝对近似比约 5/3+ε，渐近方面有 AFPTAS（高度 (1+ε)·OPT + O(hmax/ε²)）。所以条带装箱的近似性比二维装箱温和得多——这是两个「看起来对偶」的问题近似性质不同的典型例子。

基准实例与已知结果

常用基准：Hopper & Turton (2001) 的 C1–C7 共 21 个实例（物品数从十几到近两百，宽度 / 高度的比值不同，最优高度已知——它们是「完美拼合」构造出来的）；Berkey–Wang 的条带版本；以及 Burke 等人的大规模实例。评价指标是「高度与已知最优高度（或下界）的相对差」。注意比较时要说明是否允许旋转。

本站的建模方式

装箱变体家族域（bpvar）的 strippack 变体：排列编码 + 分层（shelf）解码，单条带宽度 100，物品是 [12,42]² 内的随机矩形，目标是（总高度，余隙平方和）的字典序。与文献标准的差别：分层解码只能产生层式布局（Hopper–Turton 的最优解是「完美拼合」的非层式布局，这里不可能到达）；不建模旋转；实例不是文献里的 C1–C7，不能与其已知最优对照。
