二次背包 Quadratic Knapsack（QKP）

② 结构扩展 · Feng 2026 三级分类框架（Neurocomputing 666:132135）

In brief

The Quadratic Knapsack adds pairwise profits for choosing two items together; it is strongly NP-hard. The site uses 40 items with linear values 10–100 and pairwise bonuses 0–8 between all pairs; because the quadratic terms are small relative to the linear ones, the optimum is mainly determined by the linear part and the instances are easier than Gallo's.

变量域 0-1 向量目标数 单目标（二次）复杂度 强 NP-hard关联 QUBO 的带约束特形

数学模型

模型：二次背包问题（Quadratic Knapsack Problem, QKP；Gallo、Hammer 与 Simeone 1980）——除了每件物品自己的价值，每对物品同时被选还有额外的「协同」利润：

max Σᵢ pᵢxᵢ + Σ_{i<j} p_{ij}xᵢxⱼ  s.t.  Σ wᵢxᵢ ≤ C，xᵢ∈{0,1}

当协同利润 p_{ij} ≥ 0 时，最大团问题（MCLIQUE）是它的特例（Pisinger 2007 的综述）。应用：选址（设施两两协同）、投资组合里的相关性、社会网络里的团体选择、超大规模集成电路的模块分组。

与 0-1 背包的差异

二次项让目标不再可分：一件物品的边际价值取决于已经选了谁——所以贪心和密度排序大幅失效，LP 松弛变得很弱。它是 0-1 二次规划（QUBO）加一个线性容量约束。

  • 不可近似性：QKP 比一般背包难得多——含最大团，所以对一般的稠密实例不存在多项式近似（在复杂度假设下）；对特殊支撑图（如串并联图，Rader & Woeginger 2002）则多项式可解。
  • 密度参数：Gallo 等的标准实例用 p_{ij} 非零的比例（密度 25%/50%/75%/100%）控制难度。

求解路径

  • 精确：Caprara、Pisinger 与 Toth (1999) 的分支定界（线性松弛 + 拉格朗日）；Billionnet & Soutif (2004) 的拉格朗日分解；现在 n≈300 的密集实例可求最优。
  • 元启发式（对接本站）：禁忌搜索、GRASP、遗传 / memetic、路径重连都有强结果；本站的位向量内核可直接套用。
  • 综述：Pisinger (2007) 全面总结了精确与启发式。

计算复杂度与可近似性

强 NP-困难（含最大团 / 稠密 k-子图）——与一般 0-1 背包的「弱 NP-困难」形成对比，所以没有伪多项式算法（除非 P=NP）。不存在 PTAS（在稠密 k-子图的困难性假设下，Khot 2006 的结果）。精确求解的实际规模约 n=300（密度 100%）、更稀疏时可到 n=2000。

基准实例与已知结果

标准基准：Gallo、Hammer 与 Simeone (1980) 的实例族（n=100–300，密度 25%、50%、75%、100%；p_{ij} 与 p_i 取 [1,100] 的整数，容量在 [50, Σw] 取随机）——被几乎所有后续 QKP 论文沿用；Billionnet & Soutif (2004) 的扩展集；Caprara 等 (1999) 的大规模实例。评价：与最好已知值的差。

本站的建模方式

位向量编码的变体（保真度：标准模型）：n 件物品（默认 40），线性价值 pᵢ ∈ [10,100]、重量 wᵢ ∈ [2,60]，容量为总重量的 45%（同单背包）；协同利润 p_{ij} 是 [0,8] 的随机整数，每对物品都有（密度 100%）。目标 = −(线性 + 二次价值) + 超重惩罚。

与文献标准的差别：二次项相对线性项很小（0–8 vs 10–100），所以最优解主要由线性项决定，难度明显低于 Gallo 实例（那里 p_{ij} 与 p_i 同量级）；没有密度参数；规模小。
