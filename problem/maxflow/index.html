最大流问题 Maximum Flow Problem（MF）

抽象问题类型 · Ⅺ 图与网络流类（含多项式可解的对照问题）

In brief

The Maximum Flow Problem finds the largest flow from a source to a sink under arc capacities and is solved in polynomial time (Ford–Fulkerson, Edmonds–Karp). The site is a polynomial-time contrast: a real-valued flow on every arc with an exact penalty for flow-conservation violations, compared with the Edmonds–Karp optimum — a continuous metaheuristic forced onto a problem it is not suited to.

抽象定义

模型：有向流网络——弧容量 u(e)，源点 s、汇点 t；找从 s 到 t 的最大流：

max Σ_{e∈δ⁺(s)} f(e) − Σ_{e∈δ⁻(s)} f(e)  s.t.  0 ≤ f(e) ≤ u(e)；除 s、t 外每点流入 = 流出

最大流 - 最小割定理 (Ford & Fulkerson 1956)：最大流值 = 最小割容量。应用：网络带宽、运输、二分匹配（化成流）、图像分割（图割）、项目选择。

与同族问题的结构差异

最大流是线性规划——所以它是多项式的；它也是最小费用流、二分匹配、指派问题的共同母体。作为 P 类对照，本页的有趣之处在于元启发式需要面对「流量守恒」这个等式约束：在连续决策空间里，满足 n 个等式约束的点集测度为零，随机搜索几乎碰不到可行解，必须用罚函数（或可行性修复）。

  • 整数性：容量为整数时，最大流存在整数解（总幺模性）。
  • 推广：多商品流（NP-困难的整数版）、有下界的流、带增益的流。

求解路径

  • 增广路类：Ford–Fulkerson (1956)；Edmonds–Karp (1972) 最短增广路 O(VE²)；Dinic (1970) 的分层图 O(V²E)；
  • 预流推进：Goldberg–Tarjan (1988) 的 push-relabel，O(V³)，实践中最快的一类。
  • 近线性：Chen 等 (2022) 的 almost-linear-time 最大流算法，是 2022 年理论上的突破。
  • 元启发式（对照）：本页把每条弧的流量作为实数决策变量，用精确罚函数处理流量守恒——只是为了让读者看到「连续算法 + 罚函数」在等式约束上有多吃力。

计算复杂度与可近似性

多项式可解：强多项式算法 O(VE) (Orlin 2013)；Chen、Kyng、Liu、Peng、Probst Gutenberg 与 Sachdeva (2022) 证明了 m^{1+o(1)} 时间的最大流（几乎线性）。最大流是 P-完全的 (Goldschlager、Shaw 与 Staples 1982)，所以被认为没有高效的并行算法（NC）——虽然是多项式可解的，却是「难以并行」的典型。

基准实例与已知结果

标准基准：DIMACS 第 1 届实现挑战赛（网络流，1990 年代的 washington / genrmf 生成器）、图像分割的 vision 实例集（Boykov 等的 Middlebury / Vision 数据）。评价是运行时间。元启发式用于最大流没有标准基准。

本站的建模方式

词条域里的实数向量变体（保真度：标准模型）：n_nodes=8–16 个点的随机有向流网络（每个有序点对以 0.22 的概率连一条弧，再保证存在一条 s→t 的路径），弧容量 5–20；源点 0、汇点 n−1。解 = 每条弧上的流量（[−5,5] 线性映射到 [0, 容量]），目标 = −(源点净流出) + 3 × 各中间点的流量守恒违反量之和；权重 3 > 1，使罚函数是精确的（违反守恒 1 单位至多多换来 1 单位的流）。实例里附带 Edmonds–Karp 算出的最大流值作对照；页面画弧的流量（线宽 ∝ 流量）。

与文献标准的差别：连续编码 + 罚函数求解一个本来可以精确求解的 LP，所以结果距离最大流值通常有可观的差距；这正是 P 类对照要展示的：有精确算法的问题不要交给元启发式。
