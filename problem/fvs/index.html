反馈顶点集 Feedback Vertex Set（FVS）

抽象问题类型 · Ⅱ 子集与选择类（0-1 编码）

In brief

Feedback Vertex Set removes the fewest vertices to make a graph acyclic; it is NP-hard (Karp) and has a 2-approximation. The site models only the undirected version: one bit per vertex, with the remaining cycle rank (extra edges beyond a forest) counted by union–find and penalised. The deadlock-detection example on the page concerns the directed version, which the demo does not cover.

抽象定义

删最小顶点集，使剩下的图无环（成为森林）：

min |F|  s.t.  G − F 是森林

有向图版本要求 G − F 是有向无环图（DAG），应用主要在有向版本：操作系统死锁检测（等待图里每个环是一次死锁，删最少的进程打破所有循环等待）、电路中的反馈回路切断（时序电路扫描链）、贝叶斯网络的割集条件化（Becker & Geiger 1996 就是这样引入的）。无向版本是它的基础形态，也是近似与参数化算法研究最充分的一支。

与同族问题的结构差异

与 VC 的差异：VC 只要覆盖所有「长度为 2 的结构」（边）；FVS 要打破所有长度的环——判据从「边覆盖」变成「无环性」，是一个全局的拓扑性质，所以不能像 VC 那样一条边一条边地检查。但 VC 是 FVS 的下界相关问题：删掉一个顶点覆盖后图里没有边、当然无环，所以 FVS ≤ VC。

求解路径

  • 近似：无向图有 2-近似（Bafna–Berman–Fujito 1999；Becker–Geiger 1996 独立给出），基于「按度权重分摊的局部比率」；有向图是 O(log n log log n)（Even–Naor–Schieber–Sudan 1998），是否有常数近似仍是开放问题。
  • 参数化精确算法：以解的大小 k 为参数，无向版本 FPT（Chen 等 2008 的 O(5^k·kn)，后续改进到 3.6^k 量级）；有向版本也是 FPT（Chen–Liu–Lu–O'Sullivan–Razgon 2008，这是 FPT 领域的一个里程碑）。PACE 2016 挑战赛的主题就是无向 FVS：归约规则 + 迭代压缩 + 分支的实现已能处理大规模稀疏图。
  • 本页的元启发式用位向量编码，每次评价用并查集数「删点后剩下的多余边数」。

计算复杂度与可近似性

NP-完全（Karp 1972 把有向版本列为 21 个问题之一；无向版本同样 NP-完全，Garey & Johnson 1979 GT7）。无向版本 2-近似，且在唯一博弈猜想下不可能优于 2；有向版本近似比 O(log n log log n)。在有界树宽图 / 平面图上有多项式或 PTAS。参数化：无向与有向版本对解的大小 k 都是 FPT。

基准实例与已知结果

无向 FVS 的标准基准来自 PACE 2016（Dell 等 2016）：公开的实例集覆盖了真实网络与随机图，最优值多数已知；有向版本常用的是电路基准（ISCAS 系列）与随机有向图。因为有 FPT 精确算法，评价通常看「在时限内精确解掉多少实例」而不是近似误差。

本站的建模方式

词条域里的位向量变体（保真度：标准模型，但只建了无向版本）：每个顶点一位（删 / 不删）；删掉之后用并查集数「剩下的图里多出来的边数」（圈秩，0 表示是森林）；目标 = 删掉的点数 + 1000 × 圈秩。页面上死锁检测的例子属于有向版本，本页的演示没有覆盖。
