元启发式算法百科总纲
它们解决什么问题，怎么分类，怎么选

这一页回答一个问题：「这类算法到底能解哪几类问题」。先给结论：它们解的是「解空间大到精确算法算不动」的黑盒搜索问题；你熟悉的「离散/连续/混合」只是变量类型这一个维度，完整分类还有六个正交维度。

三分钟入门：什么是元启发式？

站名里的「群智能」取其广义（群体智慧隐喻的优化算法总称，是本站的主流家风）——实际收录覆盖元启发式全谱：进化计算、物理启发、人类/社会隐喻、混合配方与多目标，不止蚁群蜂群。

一句话：元启发式 = 给「精确算法算不动的大搜索问题」用的通用试错框架——不保证最优，但在有限时间内给出足够好的解。

类比：在陌生城市找最短路线，精确算法要把每种走法都试完（n 个城市有 (n−1)!/2 条回路，30 城已超 10³⁰ 条）；元启发式是「凭经验往好的方向试探、偶尔故意绕路跳出局部」，几百步就逼近好答案。

名字拆开：heuristic = 经验法则（不保证对、但通常好用）；meta- = 高一层——不绑定具体问题，换问题只换「编码 + 邻域」两块积木，主循环通用。

什么时候用：问题规模大到精确算法超时、且「足够好」可接受时。30 个城市可以穷举，3000 个城市交给元启发式。

下一步：往下看「四连问」定位你的问题类型 → 顶部「算法 ▾」挑一个家族 → 在任意算法页直接跑 TSP 演示。

五、术语表

元启发式 (metaheuristic)
不依赖问题梯度/结构信息的高层搜索框架。名字里的 meta 意为「更高层」——它指导下层启发式（如 2-opt）怎么用。特征：随机性、可放弃最优性保证、换问题只需换编码。
探索 vs 开发 (exploration / exploitation)
探索=看没去过的地方，开发=在好解附近深挖。所有元启发式的调参本质都是平衡这对矛盾：PSO 的惯性权重、SA 的温度、GA 的变异率， knobs 不同但作用相同。
适应度地形 (fitness landscape)
把每个解的高度设为目标函数值得到的地形。单峰只有一个谷，多峰遍地局部最优。Rastrigin 函数是标准多峰考题——本站连续页可以直观看到算法被谷底困住的样子。
Pareto 支配 / Pareto 前沿
解 A 支配 B = A 在所有目标上不比 B 差且至少一个更好。不被任何解支配的解构成前沿。多目标优化的输出不是一个解，而是整条前沿——由决策者事后选择。
非支配排序 + 拥挤度 (NSGA-II)
把种群按支配关系分层（front 1/2/3…），层内用拥挤度（同一层里邻居稀疏程度）保多样性。引用数万级，是多目标进化的默认起点。
memetic / 混合算法
元启发式 + 局部搜索的混合体（道金斯 meme 的双关）。本站 TSP 侧所有种群算法的「周期 2-opt」就是 memetic 组件——「是否真在优化」自动测试专门检验「下降不是全靠局部搜索」。
编码 (encoding)
把问题的解表示成算法能操作的结构。同一算法换编码就能换问题：PSO 在连续域是实数向量+速度，到 TSP 变成排列+交换序列，到背包变成 0/1 向量。编码层是元启发式工程的主要工作量。
修复算子 (repair operator)
把违反约束的解修正为可行解。背包页的实现：超重时按「单位重量价值最低先扔」。比罚函数干净——搜索始终在可行域内进行。
基准函数 (benchmark)
公认的测试函数集：Sphere（单峰）、Rastrigin（强多峰）、Rosenbrock（香蕉谷）、Ackley（近全局平坦+边缘粗糙）。论文里的对比实验基本都在这些函数上做。
NP-hard
目前没有已知多项式时间精确算法的问题类。TSP、背包、车间调度都是。元启发式的用武之地：解不需要「最优」，只需要「够好且算得起」。
「是否真在优化」自动测试
本站的硬门槛：算法必须①显著优于随机基线 ②第 1 代到最后一带有真实迭代进步。没有它，你会写出「及格线全靠初始化播种、迭代在空转」的假算法——本站 DE 和 GWO 都栽过，教训写在各算法页。
随机搜索为什么强
低维、多峰、评价便宜时，均匀采样本身就是强基线（2D Rastrigin 上 6000 个随机样本的最好值约 0.6）。任何算法论文都必须报告与它的对比——本站每个域的算法清单里都留着 random 基线。
假跑 (fake run)
收敛曲线明明在下降，但下降并不是算法本身的功劳——比如全靠初始解质量高、或全靠附带的局部搜索。判断方法：关掉局部搜索再跑，或比较第 1 代与第 200 代的最优值；如果几乎不变，就是假跑。
随机键编码 (random keys)
把「排列」编码成一串实数，解码时按数值大小排序得到排列。它让只会处理实数的算法（PSO、CMA-ES 等）也能解 TSP、图着色这类排列问题；代价是搜索空间被扭曲，效果需要逐个验证——本站每个组合都做过「是否真在优化」检验。
吸引盆 (basin of attraction)
一个局部最优点周围「往下走最终会掉进它」的那片区域。不同算法从不同起点出发却得到同一个解，往往是掉进了同一个吸引盆。

六、建议学习路径

  1. 先在 TSP 页看懂「种群 + 收敛曲线 + 基线」三件套，理解灰线/红线的区别。
  2. 去 连续函数页看算法的「原生形态」——PSO/DE/GWO 在这里是教科书公式原样，再回 TSP 页对照理解离散化改了什么。
  3. 去 背包页理解「编码 + 约束修复」：同一批算法换到 0/1 向量上长什么样。
  4. 去 多目标页理解 Pareto 前沿：为什么输出从「一个解」变成「一群解」。
  5. 每个算法页底部的踩坑记录值得通读——离散化的坑比算法本身更深。
