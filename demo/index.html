操作指南

  1. 选一个算法，设定城市数与迭代次数，点「开始」。右上角 🌙 / ☀️ 可切换夜间/日间模式（跟随系统偏好，选择会被记住）。
  2. 左边看路径怎么进化，右边看收敛曲线：红线是全局最优，灰线是当代成本，绿虚线是最近邻基线（用来判断这个算法到底优化了多少）。
  3. 采样间隔可选每 1 / 2 / 5 / 10 代取一个点：曲线横轴始终按真实代数定位，采样只影响取点密度，不影响结果。
  4. 想用自己的数据？点「导入数据」上传 JSON [[x,y],...] 或 CSV/TXT（每行两个数字）。数据只在你的浏览器里计算，不上传。
  5. 想看清细节就拖慢速度或用「单步」；需要配图就点「导出 PNG」（路径图与收敛曲线分别导出），要原始数据就点「导出 JSON」。
  6. 想横向比较，去 算法对比页：同一批城市交给全站 45 个算法跑，曲线叠加、结果排名一次出。

实测性能

口径：城市随机种子 seed=7 · 算法种子 seed=42 · 200 代 · 同一随机实例 · 表值为最优路径长度（越小越好）。基准=随机均匀欧氏 TSP——真实路网/聚类/带约束实例形态不同，排名常反转，请用 bench.py 自行复跑。另注：45 个算法全部挂了 memetic 2-opt 组件（共同底座）——横向比的是框架增益；表中同值并列是多算法收敛到同一吸引盆，不是数据复制。

算法分类与谱系映射

每个算法的「原始形态 → 离散化到 TSP 的映射 → 复用的通用组件」。想做论文对比实验或写综述的同学，这张表就是索引。

分类算法原始形态 / 问题域离散化到 TSP 的映射复用的通用组件
构造式最近邻 NN贪心构造，天然适合组合问题每步选最近未访问城市（无需改造）—（它是别人的组件）
局部搜索2-opt 局部搜索局部改进，通用启发式2-opt 邻域：逆转路径片段，Δ 用 4 条边增量计算—（同上）
禁忌搜索 TS记忆机制 + 元启发式框架（Glover 1986）移动 = 2-opt 逆转；禁忌表存 (i,k) 到期代数；特赦准则放行破纪录移动NN 起点 · 邻域采样 · 增量 Δ 计算
迭代局部 ILS框架（Lourenço 2003），无自有算子扰动 = 双桥（2-opt 无法还原）+ 预算制 2-opt 下探 + 接受准则NN 起点 · 双桥 kick · 增量 Δ 计算
变邻域 VNS框架（Mladenović & Hansen 1997）邻域轮换 shake：双桥 / or-opt 摘段重插 / 双重双桥，有进步回 k=1NN 起点 · 多邻域算子族 · 预算制下探
Lin–Kernighan LKTSP 专用（Lin & Kernighan 1973）变深度链式 2-opt：允许链中暂时变差，按累计增益收官；卡死踢双桥NN 起点 · 增量 Δ 计算 · 双桥 kick
GRASP框架（Feo & Resende 1989），无种群RCL 半贪心构造（最近 k 个随机选一，k=2 甜区）+ 2-opt 预算制下探；每代独立重启NN 基线 · RCL 构造器 · 预算制下探
群体智能蚁群 ACO连续/图域均有；信息素标在「边」上信息素天然匹配 TSP 的边结构，几乎无需改造NN 播种 · 候选列表 · 周期 2-opt
粒子群 PSO连续实数空间（Kennedy 1995）交换序列：速度 = 一串交换操作，按比例取前缀NN 播种 · 步幅上限 · memetic 2-opt
人工蜂群 ABC函数优化（Karaboga 2005）蜜源 = 排列；邻域算子 = 片段逆转/交换NN 多起点播种 · 侦察蜂重置 · memetic 2-opt
萤火虫 FA连续空间（Yang 2008）亮度 = 1/(1+成本)；移动 = 向最亮者执行交换前缀；α 扰动 = 短 2-opt 试射NN 播种 · 步幅上限 · 汉明距离吸引度
灰狼 GWO / 鲸鱼 WOA连续空间（Mirjalili 2014/2016）向 α/β/δ 或最优鲸执行交换序列前缀；WOA 的螺旋 = 比例随 e^(b·l) 收缩NN 播种 · 步幅上限（防坍塌）· memetic 2-opt
烟花 FWA / 鱼群 AFSA连续空间（Tan 2010 / 李晓磊 2002）FWA：爆炸数量 ∝ 适应度、幅度 ∝ (1−适应度)，高斯火花 = 短 2-opt 试射；AFSA：追尾 = 向更优鱼执行交换前缀，拥挤度 δ 防挤NN 播种 · 火花贪心准入 · memetic 2-opt
布谷鸟 CS连续空间（Yang & Deb 2009）莱维飞行：小步 = 短 2-opt 试射，偶发大步 = 长片段逆转（幂律步长）NN 播种 · 弃巢重置 · memetic 2-opt
哈里斯鹰 HHO连续空间（Heidari 2019）逃逸能量 E 调度四阶段：软/硬包围 = 按 |E| 缩放交换前缀；俯冲 = 短 2-opt 试射NN 播种 · 步幅上限 · memetic 2-opt
蝙蝠 BA连续空间（Yang 2010）频率 = 向最优的交换前缀比例；响度 = 试射强度并衰减；脉冲率 = 定位开发概率并升高NN 播种 · 步幅上限 · memetic 2-opt
细菌觅食 BFO连续空间（Passino 2002）翻滚/连游 = 连续短 2-opt 试射（作用于当前解本体）；繁殖 = 排序复制；消散 = NN 重播NN 播种 · memetic 2-opt
蛾焰 MFO连续空间（Mirjalili 2015）螺旋 = 向火焰的交换前缀按 e^(b·t)·|cos| 调制；焰数逐代递减 n→1NN 播种 · 螺旋收缩 · memetic 2-opt
麻雀 SSA / 蚁狮 ALO / 蝴蝶 BOA连续空间（Xue 2020 / Mirjalili 2015 / Arora 2019），2020 前后新算法代表SSA：发现者无条件跳盆地 + 警戒远跳（扰动+预算下探作用于最优本体）；ALO：贪心游走 + 陷阱收缩；BOA：香味 ∝ 适应度调制步幅NN 播种 · 步幅上限 · memetic 2-opt
帝国 ICA / 樽海鞘 Salp / 蛙跳 SFLA连续空间（Atashpaz-Gargari 2007 / Mirjalili 2017 / Eusuff 2006）ICA：同化 = 交换前缀 + 无条件革命 + 帝国竞争换防；Salp：链首扰动下探 + 链式无条件跟随；SFLA：族群 OX 学习 + 反射踢 + 洗牌NN 播种 · 双桥扰动 · 预算制下探 · OX 交叉
花朵 FPA / 磷虾 KH / 共生 SOS / Jaya连续空间（Yang 2012 / Gandomi 2012 / Cheng 2014 / Rao 2016），组件化装配FPA：Levy 越步 = f>1 跳盆地 + 落地打磨；KH：三力串联（OX 学邻居 + 向食物源 + 扩散）；SOS：互利 OX / 偏利向最优 / 寄生挑战宿主；Jaya：向最优随机前缀 + 远离最劣（公共边占比）NN 播种 · OX 交叉 · 双桥扰动 · 预算制下探 · 公共边相似度
蜻蜓 DA / 掠食者 MPA / 乌鸦搜索 CSA连续空间（Mirjalili 2016 / Faramarzi 2020 / Askarzadeh 2016），组件化装配DA：五行为加权（分离抖动 / 对齐 OX / 聚合向最优）；MPA：布朗/莱维三相位速度博弈 + FADS 防停滞；CS：记忆偷窃（察觉概率 AP 调度跟随或乱飞）NN 播种 · OX 交叉 · 双桥扰动 · 预算制下探
天鹰 AO连续空间（Abualigah 2021），组件化装配四阶段三等分硬切换：广域双桥 → Levy 越步 → or-opt 精修 → OX 向 best + 下探NN 播种 · OX 交叉 · 双桥扰动 · 预算制下探
进化计算遗传 GA通用进化框架排列专用算子：OX 顺序交叉 + 反转变异NN 多起点播种 · 精英保留 · memetic 2-opt
差分进化 DE连续空间（Storn & Price 1997）差向量 = 交换序列；current-to-best 变异 + 低 CR 的 OX + 贪心选择NN 播种 · 步幅上限 · memetic 2-opt
教与学 TLBO班级教学隐喻（Rao 2011），连续域无参数教师阶段 = 向 teacher 的随机比例交换前缀（可反向）；学习阶段 = 配对 OX / 模仿NN 播种 · OX 交叉 · memetic 2-opt
生物地理 BBO岛屿生物地理学（Simon 2008）迁入/迁出率由 HSI 排名线性调度：差者受助（接收供体 OX）、富者输出；随机修改防早熟NN 播种 · OX 交叉 · 轮盘选择 · memetic 2-opt
克隆选择 AIS免疫系统克隆选择学说（de Castro & Von Zuben 2002）克隆扩增 ∝ 排名 + 高频变异 ∝ 亲和度（好的轻抖差的重摇）+ 变异后试射 + 新抗体注入NN 播种 · 双桥/逆转/移段变异 · 预算制下探
