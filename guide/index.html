5 分钟上手

这个站不只是介绍算法：45 个算法都能在浏览器里直接跑，你还可以换成自己的数据，再把结果导出、让别人复现。 全程在你自己的电脑上计算，数据不会上传到任何地方。

第 1 步 · 跑起来（30 秒）

  1. 打开 ▶ 演示，等页面顶部状态变成「引擎就绪」（第一次要下载约 13 MB 的浏览器内 Python，请稍等几秒）。
  2. 在「算法」里挑一个（比如粒子群、蚁群、遗传算法），点「开始」。左边是路线在一代代变短，右边是收敛曲线。
  3. 想一步一步看就点「单步」；想换一批随机城市点「换一批城市」。

打不开或一直「初始化中」？本站必须通过 http 访问（不能双击打开本地文件），浏览器需要 Chrome / Edge 111+、Firefox 114+ 或 Safari 16.4+。页面上方会写明具体原因。

第 2 步 · 换成你自己的数据（2 分钟）

不同问题的数据长得不一样，但入口一致：点页面上的「导入数据 / 导入实例」，选文件即可。导入前会先校验，哪里不对会指到具体位置（例如「items[3][0]：必须大于 0」），不会悄悄读错。

  • 旅行商（TSP）：演示页「导入数据」。支持坐标（JSON 或每行 x,y 的 CSV，也可带编号列）、标准 TSPLIB .tsp 文件、对称距离矩阵。4–500 个城市。
  • 背包、装箱、图着色、可满足性、QUBO、集合覆盖、指派、设施选址、连续函数、多目标……：到 问题 里对应的页面，点「导入实例」。每个页面都有可下载的示例文件，改成你的数据即可。
  • 本站没有的问题：到 自带问题，选一种解的形状（是/否、排序、实数），写一个目标函数，现成的几十种算法立刻可用。写法见 自带问题说明。
  • 所有格式和每个字段的含义见 数据格式说明。

看清「保真度」：问题页顶部的徽标说明这个模型有多贴近教科书定义——「标准」可以和文献对照；「教学简化」「示意模型」只是借这个问题的名字演示形态，不能把结果当成该问题的结论。导入数据时也会给出同样的提示。

第 3 步 · 导出可复现的结果（1 分钟）

运行结束后点「结果 JSON」（问题页是「导出结果」）。得到的文件里包含：完整实例、算法、随机种子、参数、逐代收敛曲线和最优解。把它发给别人，或自己留档，之后可以在任何装了 Python 的电脑上复现并核对：

python swarm.py replay 结果.json

输出「复现成功」说明同样的输入得到了逐点相同的曲线。格式见 结果文件格式。

不想开浏览器？用命令行

只需要 Python 3.8+，不用装任何包（在项目目录里）：

python swarm.py list                         # 有哪些问题域
python swarm.py list knapsack                # 某个域有哪些算法
python swarm.py template knapsack > my.json  # 拿一份示例数据，改成你的
python swarm.py check my.json                # 只校验，不运行
python swarm.py solve my.json --algo ga --iters 200 --out result.json
python swarm.py compare my.json --algos all  # 所有算法同台比一比

结果怎么看才不容易误会

  • 页面上的对比表是单个随机种子、单个实例的结果，换个种子名次可能就变了。要下结论，请多换几个种子、几个实例再看。
  • 「最优」是这个算法这次找到的最好解，不是数学上证明的最优。
  • 浏览器里的 Python 比本机慢约 2 倍。实例很大时，页面会估算「预计还需多久」；某一步算得太久，会出现「强制停止并重载引擎」按钮。
